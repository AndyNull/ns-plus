# NodeSeek 综合增强助手 (NodeSeek Helper)

一款专为 NodeSeek 社区量身打造的油猴脚本，集成了 **精准 UID 黑名单过滤**、**动态彩色/极简 SVG 头像替换** 以及 **贴边 GPU 加速悬浮球控制台**，带来更清爽、纯净的社区浏览体验。

---

## ✨ 核心特性

* **🎯 UID 精准黑名单**
* **防改名逃逸**：基于 UID 唯一标识进行屏蔽，改名换头像依然无所遁形。
* **全局覆盖**：自动折叠/屏蔽帖子列表、评论楼层内容。
* **一键快捷拉黑**：在悬浮名片弹窗和个人空间页面一键拉黑/解除，无需手动复制 UID。
* **楼层折叠反悔**：评论区被屏蔽内容支持“点击展开”，方便临时查看。


* **🎨 智能 SVG 头像替换**
* **方案 A（彩色文字）**：基于用户名 Hash 算法计算专属配色，生成高辨识度的扁平首字/双字 SVG 头像。
* **方案 B（极简轮廓）**：低饱和度灰阶边框风格，视觉极简降噪。
* **防闪烁加载**：原生头像在渲染前遮蔽替换，告别视觉闪烁与敏感图片困扰。


* **⚙️ 便捷悬浮控制面板**
* **贴边隐匿**：2 秒无操作自动半透明贴边吸附，不遮挡浏览内容。
* **自由拖拽**：纯 GPU 硬件加速拖拽，支持自由停靠屏幕左/右侧边缘。
* **配置导入/导出**：支持黑名单与个性化偏好导出为 JSON，方便多端同步与备份。

## 🚀 安装指南

1. **安装用户脚本管理器**：
* Chrome / Edge: [Tampermonkey](https://www.tampermonkey.net/)
* Firefox: [Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/) 或 [Violentmonkey](https://violentmonkey.github.io/)
* Safari: [Userscripts](https://github.com/quoid/userscripts)


2. **安装本脚本**：
* 打开脚本管理器的控制面板，点击 **添加新脚本**。
* 将脚本完整源码（`ns-plus.user.js`）粘贴到编辑器中。
* 按 `Ctrl + S`（或 `Cmd + S`）保存。


3. 访问 [NodeSeek](https://www.nodeseek.com/) 即可生效。

## 🛠️ 使用说明

### 1. 快速拉黑与解除

* **名片快捷操作**：悬停或点击任意用户头像弹出名片卡片，按钮组内新增红色的 **「拉黑」/「解除」** 按钮。
* **个人空间操作**：进入任意用户的个人空间，右侧操作栏“私信”按钮旁即可直接点击拉黑。

### 2. 控制台管理

* 点击屏幕边缘的 **齿轮悬浮球** 打开控制台：
* **切换头像风格**：可选择无（原生）、彩色文字、极简轮廓。
* **UID 黑名单管理**：可直观查看已屏蔽用户列表、单项解除屏蔽、清空全部名单，或手动输入 UID/空间链接添加。
* **备份与迁移**：点击底部的「导出配置」与「导入配置」即可迁移配置数据。

## ⚙️ 权限声明 (`@grant`)

| 权限名 | 用途 |
| --- | --- |
| `GM_addStyle` | 用于注入悬浮球、配置弹窗及楼层遮蔽相关的 CSS 样式 |
| `GM_getValue` | 读取存储在本地的黑名单列表与个性化配置 |
| `GM_setValue` | 本地持久化保存用户的屏蔽名单与界面偏好 |
